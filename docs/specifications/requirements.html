Let’s Speak ポートフォリオサイト 要件定義

1. サイトの目的・ゴール

本サイトは、開発者 大宮将嗣 の技術的実績・スキル・職務経歴をオンライン上で公開することを目的とし、以下のターゲットに向けたポートフォリオサイトを提供する。

  • フリーランス活動の雇い主（案件獲得を想定）
  • 案件の依頼を行う顧客（信頼獲得と問い合わせ誘導）
  • 同業のIT技術者（技術力・プレゼンスの向上）

併せて、AI・技術研究・趣味開発の公開・アーカイブ的役割も持つ。

2. 機能要件

  • トップページ（導線のハブ、最近の活動ハイライト）
  • 自己紹介セクション（氏名、経歴概要、PR）
  • スキル一覧（使用可能技術スタック、経験年数）
  • プロジェクト紹介
    • 一覧ページ
    • 詳細ページ（各プロジェクトの技術、期間、役割など）
  • お問い合わせ（Google フォームの埋め込み。メールアドレス運用は廃止）
  • 言語切り替え（日本語/英語）
※ 今後、必要に応じて機能追加あり（拡張性を考慮する）

3. デザイン要件（UI/UX）

  • 見やすくシンプルな構成
  • モダンかつ技術的信頼感を与えるデザイン
  • レスポンシブ対応（PC / モバイル両対応必須）
  • Tailwind CSS によるスタイル設計を基本とする

4. 技術要件（Tech Stack）

  • フロントエンド: React + TypeScript + React Router
  • UIライブラリ: Tailwind CSS
  • デプロイ環境: GitHub Pages
  • ドメイン対応:
    • メインサイト: https://lsklab.com（https://letsspeak.github.io はリダイレクト）
    • ブログ: https://blog.lsklab.com（外部構成、リンク対応）

5. コンテンツ構成

サイトルート（https://lsklab.com）に以下のセクションを設置：

  • トップ
  • 自己紹介
  • スキル一覧
  • 職務経歴
  • プロジェクト紹介
  • お問い合わせ
  • GitHub リンク
  • 外部ブログへのリンク（https://blog.lsklab.com）

※ 職務経歴・スキルなどは Markdown から生成 or 手動埋め込み

6. 非機能要件（NFR）

  • パフォーマンス: Lighthouse 高評価を目指す（PWAはオプション）
  • SEO対策: title, meta, OGP対応必須
  • アクセシビリティ: WCAG対応は意識しすぎなくてよい（一般的な対応は維持）

7. 今後の拡張方針（メモ）

  • ブログ記事の静的統合（MDXなど）も将来的に検討可能
  • 外部サービス（Google Analytics、Search Console など）の導入検討
