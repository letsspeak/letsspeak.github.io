2. お問い合わせフォーム送信時にスマホへ通知する（保留）

やりたいこと: lsklab.com のお問い合わせフォーム（Google フォーム）に回答があったときだけ、スマホに通知を出したい。

現状: 回答は Google フォームの標準機能で Gmail に通知メールが届く。ただし Gmail アプリの通知は「すべて」か「優先度の高いメールのみ」しか選べず、どちらも他のメールの通知も通ってしまうため、フォーム通知だけに絞れない。

候補（おすすめ順）

  1. Google Apps Script → Webhook
    フォームの「フォーム送信時」トリガーで Apps Script を動かし、Discord / Slack / ntfy などの Webhook に投げる。Gmail から完全に切り離せるので一番確実。
  2. Android のみ: ラベル別通知
    Gmail フィルタで専用ラベルを付け、Gmail アプリのラベルごとの通知を使う。iOS では不可。
  3. Gmail フィルタで「常に重要マーク」
    「優先度の高いメールのみ」でも Gmail が重要と判断した他のメールが鳴るため却下。

通知メールの条件（フィルタを作る場合）

from:forms-receipts-noreply@google.com
subject:(フォーム「お問い合わせ」に新しい回答があります)
